# CK2 受体与复合物研究清单

> 信息整理截至 2026 年 7 月 31 日。本文根据现有分析汇总项目涉及的实验结构，
> 用于受体构象选择、结构比较和后续审计；“待核查”表示现有分析未提供该项信息，
> 使用前应回查 PDB 条目和原始论文。本清单不预设 P15 的结合位置，实际搜索顺序、
> 位点发现规则和验收标准见 [`plan.md`](plan.md)。

## 项目对象

| 对象 | 类型 | 项目角色 | 关键信息 |
|---|---|---|---|
| P15 | 序列 `CWMSPRHLGTC` 的 11-mer 环肽 | 待对接配体 | 9-mer 活性核心 `WMSPRHLGT` 两端加 Cys，Cys1–Cys11 二硫键；在不预设位置的条件下寻找其直接结合 site |
| CK2α / CSNK2A1 | 人源催化亚基 | 主要受体 | 正式主集合使用两个 apo 构象搜索整个表面，必要时再扩展 |
| CK2α′ / CSNK2A2 | 人源催化亚基 | 主要受体 | 正式主集合使用两个 apo-like 构象搜索整个表面，必要时再扩展 |
| CK2β | 调节亚基 | 后验功能参照 | 只在候选 site 形成后评估竞争关系，不作为首轮位置约束或命中条件 |

### 两个催化亚型的候选边界

本项目不将“同一序列必须同时命中 CK2α 和 CK2α′”作为设计准入条件。
单独面向任一亚型的候选可以进入局部精修、序列优化和 MD，但必须保留它是
CK2α 轨道还是 CK2α′轨道的证据身份。若两个亚型都有合格 site，则分别优化，
再对候选并集做事后跨亚型比较。

这一决定不能解释为“抑制任一亚型就一定具有抗肿瘤效果”。原始细胞研究显示，
两个催化亚基的影响依赖细胞背景：例如在人胰腺癌模型中，分别降低两个亚基
对吉西他滨诱导细胞死亡的影响不同，而一项 C2C12 研究则用双基因敲除消除了
可检测的 CK2 催化活性。因此，本项目只把单亚型结构支持当作候选放行条件；
真实疗效还需要相应肿瘤模型中的表达、直接结合、酶活性、补偿效应和细胞实验。

依据：[胰腺癌细胞中分别降低 CK2 催化亚基的原始研究](https://pubmed.ncbi.nlm.nih.gov/20718998/)、
[CK2α/α′双基因敲除和定量蛋白质组研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC5314375/)。

### P15 来源与本项目化学状态

P15 的名称不能解释为“15 个氨基酸”。原始研究通过随机 **9-mer** 环肽噬菌体库筛选
得到活性核心 `WMSPRHLGT`，在两端加入 Cys 并形成二硫键后，实验中所称的 P15 环肽
是 11-mer `CWMSPRHLGTC`。项目没有找到“先得到 15-mer、再删除 4 个不参与结合的
残基”这一说法的原始依据。

后续临床构建体 CIGB-300（P15-Tat）为
`H-GRKKRRQRRRPPQ-βA-CWMSPRHLGTC-NH2`：P15 活性域通过 β-Ala 接到 Tat，末端
Cys 酰胺化，两个 Cys 形成二硫键。当前项目明确研究不含 Tat 和 β-Ala 的裸 P15，
因此采用以下生产主状态：

| 属性 | 主状态 | 依据与边界 |
|---|---|---|
| 序列与手性 | `CWMSPRHLGTC`，全 L | 原始 P15 活性域 |
| 闭环 | Cys1–Cys11 二硫键 | 原始环肽拓扑及 CIGB-300 结构表征 |
| N 端 | `NH3+` | 从 CIGB-300 中移除 Tat–βAla 后形成游离 N 端；属于本项目对“裸 P15”的计算假设 |
| C 端 | `CONH2` | CIGB-300 合成品和质谱结构明确为 C 端酰胺 |
| 目标 pH | 7.4 | 生理条件计算主状态，不声称等同所有体外 assay 条件 |
| His7 | `HIE`，中性 | pH 7.4 的主计算微状态；必要时以 HID/HIP 作为独立敏感性状态，不与主状态混算 |
| 形式净电荷 | +2 | 游离 N 端 +1、Arg6 +1、HIE 0、酰胺化 C 端 0 |
| 其他修饰 | 无 | Tat、β-Ala 和 TFA 对离子不属于当前裸 P15 分子 |

主要依据为 [Perea 等 2004 年原始研究](https://doi.org/10.1158/0008-5472.CAN-04-2086)、
[CIGB-300 合成品结构表征](https://doi.org/10.1002/psc.3081)和
[商品化学定义](https://www.sigmaaldrich.com/DE/en/product/sigma/sml3143)。其中游离 N 端
及 HIE 主微状态是本项目在文献未直接定义孤立裸 P15 时采用的显式计算假设。

## 阶段二全表面方法依据

2025 年的环肽 CABS-dock 研究对 38 个实验复合物执行了全局和局部对接，覆盖主链环化
与二硫键环化配体。公开方法采用距离约束保持环拓扑，先生成 10,000 个 CABS
粗粒化构象，再过滤 1,000 个低能模型并聚类为 Top-10；全原子重建和
FlexPepDock 精修属于后续步骤，不属于粗粒化全局搜索本身。该研究报告的二硫键环肽
全局对接平均 LRMSD 为 5.09 Å，说明 CABS-dock 适合作为探索性 ensemble 生成器，
但单一 Top-1 排名不能视为可靠结合姿态结论。

依据：[环肽 CABS-dock 原始研究](https://doi.org/10.1021/acs.jctc.5c00995)、
[公开 Top-10 数据仓库](https://github.com/ZalewskiMa/CABSdock-cyclic)和
[CABS-dock standalone 方法论文](https://doi.org/10.1093/bioinformatics/btz185)。

本项目因此只让阶段二负责“全表面粗粒化 site 发现”：P15 二硫键由 CABS-dock 原生
SG 距离 restraint 表达，但该 restraint 是能量惩罚项，不是全原子共价键。阶段二检查
Cys Cα 距离时只使用 `topology_feasible`，不再把它写成“二硫键已经闭合”。正式候选
直接从完整 10,000 帧 TRAF 中过滤拓扑可行且接触受体的模型，再执行 site-first、
pose-second 去重；上游 Top-1000 和 Top-10 medoid 仅作为能量过滤与公开流程基线。
CABS 粗粒化力场不会逐原子区分 P15 的
游离 N 端、C 端酰胺和 His7 微状态；这些化学细节在阶段三恢复后必须重新检查。此限制
不能用 CABS score 与亲和力直接换算来弥补。

粗粒化阈值的离线校准不把 `-in:fix_disulf` 或 Rosetta 正常退出当作化学成功。
Rosetta 官方 `ForceDisulfides` 文档明确区分“建立连接”和通过 repack 实现几何；本项目
实际测试也确认单独声明连接或只做 prepack 会留下错误 S–S 距离和严重穿插。因此校准
固定执行 `ForceDisulfides(repack=true)`、FlexPepDock prepack 和一个无 native 的局部
refine，再应用组合几何判据。依据：[Rosetta ForceDisulfides mover](https://docs.rosettacommons.org/docs/latest/scripting_documentation/RosettaScripts/Movers/movers_pages/ForceDisulfidesMover)、
[FlexPepDock 应用文档](https://docs.rosettacommons.org/docs/latest/application_documentation/docking/flex-pep-dock)。
资格控制采用 **5.5 Å 配体 CA L-RMSD**：这是 CABS-dock 环肽论文用于判断模型能否进入
FlexPepDock 有效精修吸引域的预先定义，而不是把阶段二粗粒化模型直接宣布为 CAPRI
acceptable 最终结构。接触项仍是同一 10 Å Cα 表示下的原生受体接触残基恢复率，
不冒充全原子 residue-pair Fnat。依据：[环肽 CABS-dock 原始研究](https://doi.org/10.1021/acs.jctc.5c00995)、
[CABS-dock 全局盲对接基准](https://doi.org/10.1093/nar/gkv456)和
[FlexPepDock 精修基准](https://pmc.ncbi.nlm.nih.gov/articles/PMC3125795/)。

首批开发 seed `120631..120638` 暴露了旧协议的两个独立问题：科学 QC 被当成程序异常，
以及候选只来自低能 Top-1000。随后完成的旧正式 run `120639..120646` 共 16/16 个
CABS 任务正常结束，但仍按 4 Å 和 Top-1000 合同分析，最终为 `unqualified`；该结果
是失败协议的不可变历史记录，不能在修改阈值和选择算法后补写成通过。

对两批完整 TRAF 的只读 5.5 Å 诊断显示：开发批和旧正式批都各有 5/8 seed 采样到
5.5 Å 内模型、4/8 seed 同时满足 7 Å 拓扑可行性；但 Top-1000 各自只保留 1/8，说明
主要丢失发生在 CABS 相互作用能过滤，而不是完整轨迹没有信号。进一步只在开发 seed
比较候选覆盖后发现，每 site 截取 8、16 甚至 32 个 pose 簇仍会丢失已采样的近天然
低频 basin；保留全部非冗余 pose 簇后，4 个具备合格采样的开发 seed 全部保住该 basin。

因此当前合同不再配置任意的 `max_pose_clusters_per_site`。每个 pose 簇保存几何 medoid
和最低 CABS 相互作用能模型，重复时只保存一次；真正的资源收敛发生在跨 seed 位点
支持之后，阶段三每个受体 site 只选择两个不同 seed 起点。`120639..120646` 已参与
根因诊断，当前验证改用未查看的 `120647..120654`。native 坐标只由冻结候选后的
qualification evaluator 读取，候选收集接口本身没有 native 输入。

### 全原子拓扑可恢复性校准结果

32 个 native-free 分层样本使用对齐的实验 receptor-only、cg2all 重建肽链、
`ForceDisulfides`、prepack 和单次局部 refine。每层要求至少 6/8 模型且覆盖至少 6 个
独立开发 seed 通过全部几何、位点保持和归一化 Rosetta 应变判据。

| Cys Cα 距离层 | 通过模型 | 通过 seed | 判定 |
|---|---:|---:|---|
| `≤6 Å` | 6/8 | 6/8 | 通过 |
| `6–7 Å` | 6/8 | 6/8 | 通过 |
| `7–8 Å` | 5/8 | 5/8 | 未通过 |
| `8–10 Å` 对照 | 5/8 | 5/8 | 描述性，不参与阈值选择 |

因此，最大连续通过阈值为 **7 Å**。该结果只校准标准氨基酸二硫环的粗粒化候选筛选，
不验证端基化学、亲和力排序或非二硫宏环的可迁移性。

### 阶段二参数依据审计

| 参数组 | 当前决定 | 依据与边界 |
|---|---|---|
| `mc_annealing=20`、`mc_cycles=50` | 保留 | CABS 3.0.12 默认每条 replica 生成 1,000 个快照；10 replicas 合计 10,000 帧，与 2025 环肽论文一致 |
| `mc_steps=50`、`replicas=10` | 保留 | CABS 3.0.12 的 CABSdock 默认采样长度和 REMC replica 数 |
| `replicas_dtemp=0.5`、`temperature=2.0→1.0` | 恢复上游值 | 原项目值 `0.1` 和 `3.0` 没有 legacy 或论文依据；不在无控制的情况下偏离已声明方法 |
| `filtering_count=1000`、`filtering_mode=each` | 保留 | 每条 replica 按结合能保留 100 帧，10 条轨迹合计 1,000 帧 |
| `clustering_medoids=10`、`clustering_iterations=100` | 保留为基线 | Top-10 与论文评估集一致，但 2025 研究和本项目校准均显示完整 ensemble 可能含有未被 Top-10 保留的正确模型 |
| `trajectory_contact_ca_threshold_A=10.0` | 冻结完整轨迹接触表示 | TRAF 只含 Cα；项目对 native 和 sampled pose 使用同一 10 Å Cα 接触定义，不与上游 SC 伪中心或全原子重原子接触混用 |
| `max_disulfide_ca_distance_A` | 由独立分层校准冻结 | 6/7/8 Å 是预注册候选，10 Å 只作阈值外对照；cg2all 重建肽链后 graft 对齐的实验 receptor-only，避免整体重建受体产生异常主链能；每层再经 `ForceDisulfides`、prepack 和单结构局部 refine，以 S–S、碰撞、形变、site、接触保持及按残基归一化的 `fa_rep`/主链应变组合判定 |
| `min_models_for_selection=10` | 纯技术聚类下限 | 只决定模型少于 10 个时跳过选择；不会使 topology 科学资格通过，也不会进入整个方法的 `qualified` 判定 |
| `selection_contact_jaccard_distance=0.8`、`selection_position_distance_A=12.0` | 已在新验证 seed 前冻结 | 宽松 site 预分组用于避免过早丢弃表面区域；新资格 seed 只验证该固定合同，不再从网格选值 |
| `pose_clustering_rmsd_A=4.0`、完整 pose 簇覆盖 | 冻结位点内去重 | 不按密度或能量截断低频 basin；每簇保存几何 medoid 与 energy-best，随后才按跨 seed site 支持收敛 |
| `protein_restraints=rigid,5,5.0,15.0` | 保留 | CABSdock 的实验受体默认刚性约束定义；受体构象变化由多个实验结构表达 |
| `contact_jaccard_distance=0.8`、`position_distance_A=12.0` | 已冻结跨 seed/构象 site 合并 | 支持度以独立 seed 数优先，模型数只表示簇密度；CK2α 与 CK2α′分别分析，不混合支持度 |

CK2α/CK2β 接触面，以及后验检查完整四聚体中的空间关系和可达性。

| PDB | 复合物 | 分辨率 | 构建体或状态 | 可提供的信息 |

## 不属于界面环肽参考集的条目

以下条目不计入“人源 CK2 催化亚基–界面环肽”直接参考集合，但这不代表首轮盲对接
排除 ATP 区域、CK2β 界面或任何其他受体表面区域。

| PDB 或类别 | 类型 | 不进入直接界面复合物集合的原因 | 是否保留 |
|---|---|---|---|
| **5N1V** | ATP 口袋宏环小分子复合物 | 配体不是环肽，也不占据 CK2α/CK2β 界面 | 不计入界面环肽集合；可作功能区域或受体构象参照 |
| 其他 ATP 竞争性抑制剂、糖或片段复合物 | 小分子结合态 | 不直接提供 CK2β 竞争位点的肽结合信息 | 有独立构象信息时进入第二层受体库 |
| OGT–CK2α 肽段等底物复合物 | CK2α 序列作为其他酶的底物 | CK2α 不是结构中的受体 | 排除 |
| AlphaFold 或同源预测模型 | 计算模型 | 缺少实验配体坐标 | 不计入实验结构清单 |
| 只有生化结合数据的环肽 | 无三维坐标 | 无法提供实验受体和配体构象 | 不计入结构清单 |
| 非人源 CK2α 复合物 | 非目标物种 | 不能作为主要人源对接受体 | 仅在有独特界面信息时作历史参考 |
